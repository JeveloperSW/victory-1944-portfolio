# 품질 게이트

한국어 | [English](QUALITY_GATES.en.md)

## 병합 게이트

- 요구사항과 완료 조건이 명확하다.
- 제품 헌장과 결정 로그에 충돌하지 않는다.
- 형식 검사, 정적 분석, 단위·통합 테스트가 통과한다.
- 변경된 규칙의 정상·거부·중복·동시성 경로가 검증된다.
- 데이터 마이그레이션과 롤백 또는 전진 복구가 검토된다.
- 로그·지표·알림이 개인정보를 노출하지 않는다.
- 관련 문서와 설정 스키마가 최신이다.

## 전투 게이트

- 같은 입력·규칙 버전·시드가 같은 결과 해시를 만든다.
- 과거 규칙 버전의 리플레이가 유지된다.
- 허용되지 않은 부대, 장교, 진형, 거리, 보호 대상은 서버가 거부한다.
- 전투력 차이와 반복 공격 제한이 경계값에서 작동한다.
- 결과 보고서 수치가 실제 이벤트 합계와 일치한다.

## 경제·결제 게이트

- 자원 잔액은 음수가 되지 않는다.
- 동시 구매·수령·재시도에도 한 번만 지급한다.
- 모든 변화가 원장과 원인 ID로 추적된다.
- 가격과 보상은 서버 설정에서 검증된다.
- Apple·Google 영수증은 서버에서 검증하고 환불·취소를 반영한다.
- 유료 재화와 시즌 소멸 정책이 스토어 표시와 일치한다.

## 시즌·월드 게이트

- 시즌 단계 전환과 종료를 스테이징 월드에서 재현한다.
- 유지·초기화 대상이 `PROJECT_CHARTER.md`와 일치한다.
- 중단 후 재실행해도 이중 보상·이중 초기화가 없다.
- 랭킹 결산과 보상이 동일 스냅샷을 사용한다.
- 백업, 복원, 보관, 개인정보 삭제가 충돌하지 않는다.

## 성능·복원력 게이트

- 목표 월드 부하에서 API 지연, 작업 적체, DB 잠금이 허용 범위다.
- 외부 결제·푸시·채팅 장애가 게임 권위 상태를 손상시키지 않는다.
- 재시작 후 예약 명령과 작업이 유실되지 않는다.
- 캐시 장애 시 안전하게 DB로 복구하거나 명확히 실패한다.
- 관측 대시보드와 호출 가능한 대응 절차가 있다.

## 스토어 출시 게이트

- 계정 삭제, 개인정보처리방침, 이용약관, 고객지원이 준비됐다.
- 결제 복원, 환불 처리, 데이터 수집 신고가 검증됐다.
- 채팅 필터, 신고, 차단, 운영자 제재가 실제로 동작한다.
- 역사적 심벌·폭력 표현·연령 등급을 대상 국가별로 검토했다.
- 심사용 계정과 심사 설명서가 있으며 서버가 심사 기간에 운영된다.

## 중단 기준

보안, 결제 중복, 경제 원장 불일치, 전투 비재현, 시즌 데이터 손상, 신고·차단 미작동은 출시 차단 결함이다. 일정 때문에 예외 처리하지 않는다.
